# Add Docito + Clinic Branding to All PDFs

Reference implementation: `supabase/functions/treatment-plan-generate-pdf/index.ts` (+ its `assets.ts`). Every other PDF generator must mirror its 3-zone header (Docito full logo left / entity logo center / entity name+meta right) and Docito-branded footer (icon + "Generated by Docito · docito.app" + page X of Y + verification URL where applicable).

No layout, data-field, localization, auth, file-naming, or font-system changes. Logo fetches always wrapped in try/catch with silent fallback to existing text-only header.

## Edge functions

### 1. `supabase/functions/prescription-generate-pdf/index.ts`
- Expand doctor lookup to also pull `logo_url, practice_id, practices(name, address, phone, logo_url)`.
- Resolve `entityLogoUrl = practiceLogoUrl ?? doctorLogoUrl`, `practiceName`, `practiceAddress`.
- In existing header drawer, add center entity-logo zone (fetchImageBytes + embedPng/embedJpg + drawImage) and right-side practice name/address lines. Footer already correct.

### 2. `supabase/functions/invoice-generate-pdf/index.ts`
- Expand every branch of the entity-resolution chain to also select `logo_url` and `address` (plus `phone` where present): practices, doctors (incl. nested `practices(name, address, logo_url)`), pharmacies, labs, imaging.
- Compute `entityLogoUrl`, `entityAddress`.
- In `drawHeader`, add centered entity logo and right-side entity address line — matches treatment-plan 3-zone layout.

### 3. `supabase/functions/referral-generate-pdf/index.ts`
- Import `DOCITO_LOGO_FULL_PNG_BASE64` from `./assets.ts`.
- Replace every `docito.live` string with `docito.app`.
- In the `clinic` / `doctor` referrer branches, also fetch `logo_url, address` from practices/doctors. Store `entityLogoUrl`, `entityAddress`.
- In `renderAll` header block, replace current Docito-icon-only header with 3-zone layout: full Docito logo left, entity logo center (fetchImageBytes + embedPng/embedJpg), referrer name + address right.

### 4. `supabase/functions/superbill-generate-pdf/index.ts`
- Expand practices select to `name, address, phone, logo_url`; doctors select to `user_id, full_name, logo_url`.
- `entityLogoUrl = practiceLogoUrl || doctorLogoUrl`.
- In `drawHeader`, add centered entity logo via fetchImageBytes/embed/drawImage and a third right-side line for practice address.

### 5. `supabase/functions/appointment-summary-pdf/index.ts`
- No `assets.ts` exists for this function — inline `DOCITO_LOGO_FULL_PNG_BASE64` and `DOCITO_LOGO_PNG_BASE64` constants at the top of this file (copy from the treatment-plan assets.ts).

- Add a `drawHeader()` helper modeled on treatment-plan; call it after `new jsPDF()` and after every `doc.addPage()`.
- Rewrite footer loop to: Docito icon + "Generated by Docito · docito.app" + "Page X of Y" (matches superbill/invoice).
